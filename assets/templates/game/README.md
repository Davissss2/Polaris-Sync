# $name

Game workspace, generated by Polaris.

Every service Roblox creates for a new place is mapped to its own
folder, so anything you build in Studio is written back to disk and
anything you edit locally shows up in Studio.

## Getting Started

Start the local server and open Roblox Studio:

```bash
polaris serve
```

Build a place file from the project:

```bash
polaris build
```

## Removing a service

Don't use a service? Delete its entry from `default.project.json` and
its folder. Polaris only syncs what the project file maps.

Missing a service? Run `polaris workspace expand` to add everything
that is missing without touching the folders you already have.
